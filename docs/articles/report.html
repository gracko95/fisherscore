1 Introduction

Counts such as the number of doctor visits are often overdispersed: their variance is larger than their mean, which the Poisson model does not allow. They often also contain more zeros than a Poisson (or even a negative binomial) distribution predicts. The negative binomial (NB2) model handles overdispersion through a dispersion parameter θ\theta. The zero-inflated negative binomial (ZINB) model also allows a separate process that produces “structural” zeros.

The nbzinbKoo package fits both models with algorithms written from scratch: iteratively reweighted least squares (IRLS) alternated with Newton–Raphson for NB regression, and an EM algorithm whose M-steps are IRLS fits for ZINB regression. It does not call optim() or any other general-purpose optimizer. This report describes the methods (Section 2) and the package (Section 3), checks the results against MASS::glm.nb() and pscl::zeroinfl() (Section 4), studies the ZINB estimator by simulation (Section 5), and analyzes physician office visits in the NMES1988 data (Section 6).

2 Methods

2.1 Negative binomial regression

For counts yiy_i with covariates xix_i and offset oio_i, the NB2 model has log⁡μi=ηi=xi⊤β+oi\log\mu_i = \eta_i = x_i^\top\beta + o_i and Var⁡(Yi)=μi+μi2/θ\operatorname{Var}(Y_i) = \mu_i + \mu_i^2/\theta. With prior weights aia_i (all 1 in an ordinary fit) the log-likelihood is ℓ(β,θ)=∑iai[log⁡Γ(yi+θ)−log⁡Γ(θ)−log⁡yi!+θlog⁡θ+yilog⁡μi−(θ+yi)log⁡(θ+μi)]. \ell(\beta,\theta) = \sum_i a_i\Big[\log\Gamma(y_i+\theta) - \log\Gamma(\theta) - \log y_i! + \theta\log\theta + y_i\log\mu_i - (\theta+y_i)\log(\theta+\mu_i)\Big].

IRLS for β\beta (θ\theta fixed). Fisher scoring for a log-link GLM with variance V(μ)=μ+μ2/θV(\mu) = \mu + \mu^2/\theta is weighted least squares with wi=ai(∂μi/∂ηi)2V(μi)=aiθμiθ+μi,zi=(ηi−oi)+yi−μiμi,β(t+1)=(X⊤WX)−1X⊤Wz. w_i = a_i\frac{(\partial\mu_i/\partial\eta_i)^2}{V(\mu_i)} = a_i\frac{\theta\mu_i}{\theta+\mu_i}, \qquad z_i = (\eta_i - o_i) + \frac{y_i-\mu_i}{\mu_i}, \qquad \beta^{(t+1)} = (X^\top WX)^{-1}X^\top Wz . The least-squares step is solved by a QR decomposition of W1/2XW^{1/2}X, and a step that lowers ℓ\ell is halved.

Newton–Raphson for θ\theta (β\beta fixed). With U(θ)=∑iai[ψ(yi+θ)−ψ(θ)+log⁡θ+1−log⁡(θ+μi)−(yi+θ)/(θ+μi)]U(\theta) = \sum_i a_i[\psi(y_i+\theta) - \psi(\theta) + \log\theta + 1 - \log(\theta+\mu_i) - (y_i+\theta)/(\theta+\mu_i)] and H(θ)=∑iai[ψ′(yi+θ)−ψ′(θ)+1/θ−2/(θ+μi)+(yi+θ)/(θ+μi)2]H(\theta) = \sum_i a_i[\psi'(y_i+\theta) - \psi'(\theta) + 1/\theta - 2/(\theta+\mu_i) + (y_i+\theta)/(\theta+\mu_i)^2], we update ϕ=log⁡θ\phi = \log\theta, which keeps θ>0\theta>0: ϕ←ϕ−Uϕ/Hϕ\phi \leftarrow \phi - U_\phi/H_\phi with Uϕ=θUU_\phi = \theta U and Hϕ=θ2H+θUH_\phi = \theta^2H + \theta U.

Outer loop and standard errors. We start from a Poisson IRLS fit and the moment estimate θ(0)=∑iai/∑iai(yi/μi−1)2\theta^{(0)} = \sum_i a_i / \sum_i a_i(y_i/\mu_i - 1)^2, then alternate the two steps until ℓ\ell changes by less than 10−810^{-8}. At convergence Var̂(β̂)=(X⊤ŴX)−1\widehat{\operatorname{Var}}(\hat\beta) = (X^\top\hat WX)^{-1} (treating θ\theta as known, as glm.nb() does) and SE⁡(θ̂)={−H(θ̂)}−1/2\operatorname{SE}(\hat\theta) = \{-H(\hat\theta)\}^{-1/2}.

2.2 Zero-inflated negative binomial regression

The ZINB model mixes a point mass at zero (probability πi\pi_i, logit⁡πi=zi⊤γ\operatorname{logit}\pi_i = z_i^\top\gamma) with an NB(μi,θ)(\mu_i,\theta) count distribution. Its observed-data log-likelihood is ℓ(β,γ,θ)=∑yi=0log⁡[πi+(1−πi)fNB(0;μi,θ)]+∑yi>0[log⁡(1−πi)+log⁡fNB(yi;μi,θ)], \ell(\beta,\gamma,\theta) = \sum_{y_i=0}\log\big[\pi_i + (1-\pi_i)f_{NB}(0;\mu_i,\theta)\big] + \sum_{y_i>0}\big[\log(1-\pi_i) + \log f_{NB}(y_i;\mu_i,\theta)\big], with fNB(0;μ,θ)={θ/(θ+μ)}θf_{NB}(0;\mu,\theta) = \{\theta/(\theta+\mu)\}^\theta. Because of the log of a sum, this is not an exponential-family likelihood and IRLS cannot be applied to it directly. We maximize it by EM, treating the indicator DiD_i of a structural zero as missing data.

  • E-step. τi=P(Di=1∣yi)=πi/{πi+(1−πi)fNB(0;μi,θ)}\tau_i = P(D_i = 1\mid y_i) = \pi_i/\{\pi_i + (1-\pi_i)f_{NB}(0;\mu_i,\theta)\} if yi=0y_i = 0 and τi=0\tau_i = 0 otherwise.
  • M-step, zero part. Maximize ∑i[τilog⁡πi+(1−τi)log⁡(1−πi)]\sum_i[\tau_i\log\pi_i + (1-\tau_i)\log(1-\pi_i)]: a logistic regression with fractional response τi\tau_i, fitted by IRLS with wi=πi(1−πi)w_i = \pi_i(1-\pi_i) and zi=zi⊤γ+(τi−πi)/{πi(1−πi)}z_i = z_i^\top\gamma + (\tau_i - \pi_i)/\{\pi_i(1-\pi_i)\}.
  • M-step, count part. Maximize ∑i(1−τi)log⁡fNB(yi;μi,θ)\sum_i(1-\tau_i)\log f_{NB}(y_i;\mu_i,\theta): exactly the NB fit above with prior weights ai=1−τia_i = 1-\tau_i (the package reuses the same code).

EM starts from the NB fit for (β,θ)(\beta,\theta) and a logistic IRLS fit of I(yi=0)I(y_i=0) on ziz_i for γ\gamma, and stops when ℓ\ell changes by less than 10−810^{-8}. The package records ℓ\ell at every iteration and warns if it ever decreases.

Standard errors. We invert the observed information of ℓ\ell in (β,γ,ϕ=log⁡θ)(\beta,\gamma,\phi=\log\theta), computed analytically. For observation ii let hi=log⁡fNB(yi;μi,θ)h_i = \log f_{NB}(y_i;\mu_i,\theta) and ρi=1−τi\rho_i = 1-\tau_i. Then ∂ℓi∂ηz=τi−πi,∂ℓi∂a=ρiha,∂2ℓi∂ηz2=τi(1−τi)−πi(1−πi),∂2ℓi∂ηz∂a=−τiρiha,∂2ℓi∂a∂b=ρihab+τiρihahb, \frac{\partial\ell_i}{\partial\eta_{z}} = \tau_i - \pi_i,\quad \frac{\partial\ell_i}{\partial a} = \rho_i h_a,\quad \frac{\partial^2\ell_i}{\partial\eta_z^2} = \tau_i(1-\tau_i) - \pi_i(1-\pi_i),\quad \frac{\partial^2\ell_i}{\partial\eta_z\,\partial a} = -\tau_i\rho_i h_a,\quad \frac{\partial^2\ell_i}{\partial a\,\partial b} = \rho_i h_{ab} + \tau_i\rho_i h_a h_b, for a,b∈{ηc,ϕ}a,b\in\{\eta_c,\phi\}, where hη=θ(y−μ)/(θ+μ)h_{\eta} = \theta(y-\mu)/(\theta+\mu), hηη=−θμ(θ+y)/(θ+μ)2h_{\eta\eta} = -\theta\mu(\theta+y)/(\theta+\mu)^2, hϕ=θUih_\phi = \theta U_i, hϕϕ=θ2Hi+θUih_{\phi\phi} = \theta^2H_i + \theta U_i and hηϕ=θμ(y−μ)/(θ+μ)2h_{\eta\phi} = \theta\mu(y-\mu)/(\theta+\mu)^2. The chain rule (∂ηc/∂β=xi\partial\eta_c/\partial\beta = x_i, ∂ηz/∂γ=zi\partial\eta_z/\partial\gamma = z_i) gives the blocks of the Hessian. The test suite checks this Hessian against numDeriv::hessian() of the package’s own log-likelihood.

3 The R package

The package is installed with devtools::install_github("gracko95/nbzinbKoo"). Its main functions are:

Function Purpose
nbreg(formula, data, offset, control) NB2 regression (IRLS + Newton–Raphson)
zinbreg(formula, data, offset, control) ZINB regression (EM with IRLS M-steps); formula y ~ x | z
nbreg_control(), zinbreg_control() tolerances, maximum iterations, trace, Hessian type

Both functions return S3 objects (classes "nbreg" and "zinbreg") with methods print, summary, coef, vcov, logLik (so AIC() and BIC() work), fitted, residuals (response and Pearson), nobs and predict (with newdata; for zinbreg, type = "response", "count", "zero" or "prob0"). The code is organized as R/nbreg.R (NB engine), R/zinbreg.R (EM engine and analytic Hessian), R/methods.R and R/utils.R (log-likelihood, θ\theta derivatives, weighted least squares).

4 Benchmarking

We compare nbreg() with MASS::glm.nb() and zinbreg() with pscl::zeroinfl(dist = "negbin") on bioChemists (Long, 1997) and NMES1988 (Deb and Trivedi, 1997). The reference functions were run with tight tolerances (epsilon = 1e-10 and reltol = 1e-12). Table 1 gives the maximum absolute differences, which are all far below the required 10−510^{-5} (NB coefficients and SEs), 10−410^{-4} (NB θ\theta and log-likelihood) and 10−310^{-3} (ZINB). A positive log-likelihood difference means that our fit attains a slightly higher maximum.

The side-by-side tables for the other three fits are in the Appendix (Table 7, Table 8 and Table 9). EM needs more iterations than BFGS and is slower (each M-step is itself an iterative fit), but every run converged and the log-likelihood never decreased.

6 Data analysis: physician office visits (NMES1988)

The NMES1988 data record the number of physician office visits (visits) for 4406 people aged 66 and over. The mean is 5.77 but the variance is 45.7, about 8 times larger, which is strong evidence of overdispersion. 15.5% of the people made no visits, while a Poisson distribution with the same mean predicts only 0.31% (Figure 1).

f_count <- visits ~ hospital + health + chronic + gender + school + insurance
m_pois <- glm(f_count, family = poisson, data = NMES1988)      # reference only
m_nb   <- nbreg(f_count, data = NMES1988)
m_zinb <- zinbreg(visits ~ hospital + health + chronic + gender + school + insurance |
                    hospital + chronic + gender + school + insurance, data = NMES1988)

The data contain 683 zeros.

The NB model estimates θ̂=1.21\hat\theta = 1.21 (SE 0.034), and the ZINB model θ̂=1.48\hat\theta = 1.48.
