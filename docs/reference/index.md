# Package index

## Regression models

NB and ZINB regression fitted by IRLS, Newton-Raphson and EM.

- [`nbreg()`](https://gracko95.github.io/nbzinbKoo/reference/nbreg.md) :
  Negative binomial regression by IRLS and Newton-Raphson
- [`zinbreg()`](https://gracko95.github.io/nbzinbKoo/reference/zinbreg.md)
  : Zero-inflated negative binomial regression by EM with IRLS M-steps
- [`nbreg_control()`](https://gracko95.github.io/nbzinbKoo/reference/nbreg_control.md)
  : Control parameters for nbreg()
- [`zinbreg_control()`](https://gracko95.github.io/nbzinbKoo/reference/zinbreg_control.md)
  : Control parameters for zinbreg()
