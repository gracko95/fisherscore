# nbzinbKoo: Negative Binomial and Zero-Inflated Negative Binomial Regression by IRLS

Fits negative binomial (NB2) regression by iteratively reweighted least
squares alternated with Newton-Raphson for the dispersion parameter, and
zero-inflated negative binomial regression by an EM algorithm whose
M-steps are IRLS fits, without calling a general-purpose optimizer.
Standard errors for the zero-inflated model come from the analytic
observed information matrix.
